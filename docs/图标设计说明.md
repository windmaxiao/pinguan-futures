# 「品观」视觉图标设计说明

> **设计对象**：品观 · 期货品种数据与研究台（`mp-data`）
> **文件格式**：SVG 矢量
> **最后更新**：2026-11-24

---

## 一、设计理念

图标要同时说清三件事：**这是什么品种、这是什么工具、它想解决什么问题**。

```
            ┌──────────────────────────────────────────┐
            │          品观 · 图标意象               │
            └──────────────────┬───────────────────────┘
                               │
    ┌──────────────────────────┼──────────────────────────┐
    ▼                          ▼                          ▼
┌──────────────┐        ┌──────────────┐          ┌──────────────┐
│ 大豆实体     │   ＋   │ 三联 K 线    │    ＋    │ 新芽 + 星芒  │
│ 品种属性     │        │ 交易与结构   │          │ 预期与研判   │
└──────────────┘        └──────────────┘          └──────────────┘
```

1. **大豆形态**：金色豆体，象征农产品的现货与压榨链条。
   豆脐（胚眼）做成内凹弧线，隐喻"由表及里看基本面"。
2. **三联 K 线**：豆体内生长出三根递增柱线，配上下影线。
   既指 1/5/9 月的合约轮换，也指基差、月差、价差这套期限结构。
3. **新芽与星芒**：顶部嫩芽代表从现实向预期的传导；右上星芒呼应"观"字，
   寓意在噪音里定位主要矛盾。

## 二、图标清单

| 文件 | viewBox | 适用场景 |
|---|---|---|
| `favicon.svg` | 64 × 64 | 浏览器标签页、移动端书签 |
| `logo.svg` | 256 × 256 | 方形主徽标、README 封面、社交头像 |
| `logo-horizontal.svg` | 460 × 88 | 页面 Header、研报标题横幅 |

三档尺寸对应三种使用距离，**小尺寸不应直接缩放大图**——所以 favicon 是单独绘制的简化版，
去掉了渐变、滤镜、雷达网格和趋势虚线。

### 文件放置规则

```
源文件    mp-data/app/assets/*.svg     ← 纳入版本控制
          ↓ render.py 每次渲染复制
产物      mp-data/site/*.svg           ← .gitignore 忽略，构建输出
```

**不要把源文件直接放在 `site/`**。那是构建输出目录，被 `.gitignore` 忽略，
换一台机器部署时这些图标不会跟着走，favicon 会 404。

> ⚠️ **当前状态**：三个 SVG 仍在 `mp-data/site/`，尚未迁移到 `app/assets/`，
> 也未被 `render.py` 复制。详见「六、待办」。

## 三、色彩

| 角色 | 图标用色 | 页面 CSS 变量 | 说明 |
|---|---|---|---|
| 底板墨绿 | `#1f3b30` → `#0e1f18` | `--accent: #224038` | 图标比页面强调色略深，更沉稳 |
| 大豆琥珀金 | `#fed678` → `#c9821d` | **无对应变量** | 图标独有，页面尚未定义金色 |
| 生机青绿 | `#3b7a57` → `#8fd6a2` | `--green: #2d5542`、`--olive: #5d6e44` | 图标偏亮，页面偏灰绿 |
| 象牙暖白 | `#f9f8f3` | `--surface: #f9f8f3` | 完全一致 |

页面现有变量（`style.css`）：`--ink --muted --line --paper --surface --olive --green --accent --rust`。
**没有 `--gold`**——如果以后想让图标与页面完全同源，需要先在 CSS 里补一个金色变量。

## 四、在项目中引用

### 1. Favicon（部分页面已接入）

`render.py` 的 `_page_head()` 已输出：

```html
<link rel="icon" href="favicon.svg" type="image/svg+xml">
```

已接入的页面：看板、周度、录入、解锁、管理（都在站点根目录，路径正确）。

**尚未接入的页面**：

| 页面 | 原因 |
|---|---|
| `brief/xxx.html`、`macro/xxx.html` | `brief.py` 有自己的 `_page_head`，没有 favicon 链接 |
| `brief.html`、`macro.html` | 同上 |
| `journal.html` | 渲染模板里漏了 favicon 行 |

这些页面打开时浏览器标签是空白图标，不是报错。修法见「六、待办」第 3 条。

### 2. 页面 Header 横版 Logo（未接入）

现在的 Header 是纯文字 `<h1>品观 · 豆粕</h1>` + 导航。
若要换成横版 logo：

```html
<a href="index.html" class="brand">
  <img src="logo-horizontal.svg" alt="品观" height="40">
</a>
```

前提是 `logo-horizontal.svg` 已在站点根目录。

### 3. README / 文档

```markdown
<img src="mp-data/app/assets/favicon.svg" width="32" height="32" alt="品观"> 品观 · 期货品种数据与研究台
```

用**仓库相对路径**，不要用 `file:///e:/...` 这种本地绝对路径——别人克隆下来打不开。

## 五、设计评审意见

以下是看过实际渲染后的问题，按严重度排列。

### 🔴 文件未纳入版本控制
见第二节。当前状态部署到干净环境必然 404。

### 🟠 方形 logo 元素过多
`logo.svg` 叠了 7 层：雷达圈 ×2、十字线、星标、趋势虚线、新芽、豆脐、K 线。

缩到 64–96px（侧边栏、头像）时，雷达网格会变成脏点、虚线会糊成一片。

**建议**：删掉雷达网格和趋势虚线，只留「豆体 + K 线 + 豆脐 + 新芽 + 星标」。

### 🟠 K 线穿出豆体
三根柱子的影线顶端超出金色圆形边界，小尺寸下看起来像"天线"，
豆体和 K 线不再是整体。

**建议**：K 线整体收进豆体内。

### 🟡 横版 logo 的层次与文案

1. **`MP-DATA` 徽章过重**：深绿实心块与主标题视觉重量接近，抢注意力。
   建议改描边或浅色底。
2. **分隔符混用**：副标题里同时出现 `|` 和 `·`。
   `期货品种数据与研究台 | 一个品种 · 一套框架 · 一页纸`
   建议统一。
3. **品牌名写死了"豆粕"**：加甲醇、玉米后每加一个品种就要重做 logo。
   建议主标题固定「品观」，品种作为可变标签。

### 🟡 豆脐造型
favicon 里那条棕色弧线更像括号 `(`，不太像豆脐。
真实大豆的豆脐是贴近边缘的浅色椭圆线。
建议改成沿豆体内缘的弧形凹线，或直接去掉（K 线已足够表达）。

### 🟡 简报页和复盘页没有 favicon
`brief.py` 的 `_page_head` 和 `render_journal` 的模板都没输出 favicon 链接，
所以这几页的浏览器标签是空白图标。

修法：`brief.py` 的 `_page_head` 加一行 `%sfavicon.svg`（复用已有的 `prefix`），
`render_journal` 的 head 同样补上。
