## 一、合约基础：先把豆粕“摸熟”

做豆粕之前，合约参数需要形成肌肉记忆，而不是临时去查。

| 项目 | 规格 |
|---|---|
| 交易单位 | **10吨/手**，价格每变动1元/吨，一手盈亏 **10元** |
| 最小变动价位 | 1元/吨（一跳10元） |
| 主力合约轮换 | **1月 → 5月 → 9月**，当前主力通常为 **M2701** |
| 交易时间 | 日盘 9:00–10:15、10:30–11:30、13:30–15:00；夜盘 21:00–23:00 |
| 交易所基础保证金 | **7%**（期货公司会加收，实际以你的账户为准） |
| 手续费 | 交易所标准 **1.5元/手**，开平双边合计约3元；自助开户默认可能加收到5–9元/手，开户时协商过则按协商价执行 |

### 1.1 一手要多少钱

按主力合约 **3000–3150元/吨** 测算：

- 合约价值：约 **3–3.15万元/手**
- 交易所保证金7%：约 **2100–2200元/手**
- 期货公司加收后实际占用：通常 **3000–4000元/手**

一跳10元，意味着价格波动 **30–50点**，一手盈亏就是 **300–500元**。这个量级决定了你的仓位和止损必须提前算清楚，而不是开了仓再想。

### 1.2 必须知道的细节

- **临近交割月或市场剧烈波动时**，交易所会临时上调保证金比例，期货公司同步上浮。
- **不要在临近交割的合约上恋战**，主力合约切换后及时移仓。
- 豆粕主力合约轮换有节奏：1月合约交易到前一年12月前后，5月合约交易到当年4月前后，9月合约交易到当年8月前后。专注豆粕，必须对主力切换时间有感知。

## 二、分析框架：成本端、供给端、需求端、价差结构

专注豆粕，不需要每天扫描所有品种，但需要对豆粕的**成本端、供给端、需求端、价差结构**保持连续跟踪。

### 2.1 成本端：美豆是锚

豆粕价格紧贴美豆走势。核心跟踪变量：

- **USDA月度供需报告**：单产、期末库存、出口预估
- **美豆出口销售与对华装运**：中国采购节奏
- **中美贸易政策与关税**：进口成本与采购意愿
- **南美天气与播种/生长进度**：远月成本预期
- **汇率、海运费**：进口大豆到港成本

**逻辑**：美豆库存收紧、出口强劲、贸易摩擦推升进口成本 → 豆粕成本抬升 → 利多；反之则利空。但成本端利多能否传导为国内上涨，还要看内盘供给和需求。

### 2.2 供给端：看油厂和到港

- **大豆到港量**
- **油厂开机率、压榨利润**
- **油厂大豆库存、豆粕库存周度变化**
- **通关政策与检验节奏**：短期供给节奏扰动

**逻辑**：到港量大、开机率高、豆粕库存高 → 现货供应压力大 → 利空，尤其是基差和近月合约；通关延长、检验收紧 → 短期供给节奏受扰 → 阶段性利多情绪。

### 2.3 需求端：看养殖

- **生猪存栏**
- **生猪养殖利润**
- **饲料企业豆粕添加比例与库存天数**
- **水产养殖季节性需求**（菜粕替代关系）

**逻辑**：生猪存栏高位 → 刚性需求支撑；养殖深度亏损 → 补栏放缓、饲料企业随用随采 → 需求增速受限。需求端通常是**慢变量**，更多决定需求上限，而非短期方向。

### 2.4 价差结构：基差与月差

- **现货基差 = 现货价 - 期货价**
- **月间价差**：1-5、5-9、9-1
- **豆粕-菜粕价差**

**逻辑**：基差走强/正基差扩大 → 现货紧张或期货预期过弱，对近月有支撑；基差走弱/深度贴水 → 现货宽松，压制近月。月差反映市场对近远月供需的预期差异。

## 四、主要交易手段：从单边到套利

### 4.1 单边趋势跟踪（最直接，也最考验纪律）

- **做法**：判断方向，做多或做空。
- **驱动**：豆粕单边行情往往由**超预期的供给冲击**驱动，如USDA报告大幅调整、南美极端天气、贸易政策突变。
- **关键**：等待“预期差”出现，而不是在震荡市中频繁消耗。例如，2026年11月USDA报告意外下调美豆期末库存至3亿蒲，显著低于市场预估，直接触发美豆及连粕强势反弹。
- **注意**：震荡市中单边追涨杀跌，容易被手续费和反复止损慢性磨损。

### 4.2 跨期套利（用相对价差替代绝对方向）

- **做法**：利用豆粕1月、5月、9月合约间的价差波动。
- **场景**：近月因现货高库存承压，远月受成本支撑时，可能出现**反套**（空近月、多远月）机会；反之可考虑正套。
- **优点**：风控效果通常优于单边投机。
- **要求**：需要对产业逻辑和价差历史区间有更深理解。

### 4.3 跨品种套利

- **豆粕与菜粕**：两者存在替代关系，价差变化提供套利窗口。
- **注意**：替代逻辑受水产季节、菜粕供给、饲料配方调整影响，不是简单的价差回归。

### 4.4 套期保值（理解产业视角）

- 如果你是饲料企业或油厂，套保是锁定利润的工具。
- 对个人投机者，理解套保盘动向同样重要：**油厂在盘面卖出套保的力度，本身就是豆粕上方压力的来源之一**。当压榨利润深度倒挂时，油厂的套保意愿和节奏变化，会间接影响期货价格的顶部区域。

### 4.5 期权组合（进阶风险管理工具）

- 豆粕期权可用于构建更精细的策略，例如预期波动加大时买入跨式组合，震荡市中卖出宽跨式组合赚取时间价值。
- **建议**：在单边和套利跑通后再考虑，需要额外期权知识。

## 五、信息如何合成交易判断：矛盾框架

单条信息本身不构成交易理由。专注豆粕的优势，在于把信息放入一个**矛盾框架**中权衡。

### 5.1 当前核心矛盾示例

**外盘的成本支撑（USDA利多、出口强劲） VS. 内盘的现实压力（库存高企、基差疲弱、需求平淡）。**

- **当外盘利多发酵时**（如USDA报告后），国内豆粕会**跟涨**，因为成本端抬升了估值底线。
- **但上涨的持续性受制于内盘**：高库存和弱基差意味着每一次反弹都可能面临**现货套保盘和获利了结**的压力。因此，行情更容易表现为**震荡偏强**，而非流畅的单边上涨。
- **未来的破局变量**：交易主线正从北美产量转向**南美天气**。如果南美出现实质性干旱威胁，远月天气升水将被注入，可能推动一轮由**预期驱动**的上涨；反之，如果南美丰产兑现，内盘高库存压力将重新占据主导。

### 5.2 每日判断模板

每天问自己三个问题：

1. **当前市场正在交易哪一对矛盾？**  
   是外盘成本抬升，还是内盘库存压力？是南美天气预期，还是现货基差走弱？
2. **今天的新信息是在强化还是削弱这个矛盾？**  
   例如：USDA报告利多 → 强化成本支撑；油厂库存继续累积 → 强化内盘压力。
3. **我的持仓逻辑是否仍然成立？**  
   如果逻辑被削弱或破坏，减仓或离场；如果逻辑强化，按规则持有或加仓（加仓需有独立规则）。

## 六、风控与仓位管理：把规则写死

这是从“有权限”到“能活下来”最关键的一步。

### 6.1 仓位规则

- 初始实盘资金 **5000–10000元**，**只做1手**。
- 仓位控制在总资金的 **20%以内**。
- 1手豆粕保证金约3000–4000元，5000元账户做1手已接近满仓临界值，不要被“一手很便宜”的错觉诱导加仓。

### 6.2 单笔止损规则

- 单笔亏损必须控制在**总资金的2%以内**。
- 以5000元账户为例，单笔最大亏损 **100元**；换算成豆粕点数，就是 **10个点**。
- 这意味着入场点必须选在离防守位足够近的地方，而不是开了仓再找止损。
- 做多止损设在入场点下方30–50点，对应一手亏损300–500元。这个幅度已超出5000元账户的2%上限，所以**账户资金与止损点数必须匹配**：如果坚持30–50点止损，账户至少需要 **1.5–2.5万元** 才能让单笔亏损落在2%以内。

### 6.3 不扛单、不隔夜（新手阶段）

- 杠杆约10倍，价格反向波动1%，本金亏损10%。
- 重仓或满仓下，一次跳空就可能造成不可逆损伤。
- **USDA报告发布日、极端天气预警时，务必空仓观望**。
- 新手阶段尽量日内了结，减少隔夜暴露。

### 6.4 先用模拟，再上实盘

- 至少进行 **1–3个月模拟盘**。
- 熟悉日盘/夜盘波动节奏、主力合约切换、报告发布前后的价格反应。
- 模拟阶段目标不是“赚钱”，而是验证：止损是否执行得下去、仓位是否让你睡得着。

### 6.5 纪律清单（开仓前必查）

- [ ] 我是否清楚这笔交易在交易哪个矛盾？
- [ ] 我的入场逻辑是什么？如果逻辑被破坏，什么信号证明我错了？
- [ ] 止损位在哪里？止损点数对应亏损金额是多少？是否超过总资金2%？
- [ ] 当前仓位是否超过总资金20%？
- [ ] 今天是否有USDA报告、重要数据或极端天气预警？是否需要空仓？
- [ ] 我是否在追涨杀跌，而不是等待计划内的信号？
- [ ] 我是否能接受这笔交易亏损？是否会影响睡眠？

## 七、从模拟到实盘的启动顺序

### 第1–2周：只看盘，不交易

- 打开豆粕主力合约，记录每日高低点、成交量变化、夜盘与日盘衔接。
- 观察USDA报告、进口数据、油厂库存发布前后的价格反应模式。
- 熟悉1→5→9的主力轮换节奏。

### 第3–4周：模拟盘“条件单式”练习

- 只做一种形态，例如“均线多头排列 + 放量突破关键位”。
- 严格设好止损，记录每一笔的盈亏比和是否执行止损。
- 目标：积累**可重复的动作**，而非盈利。

### 模拟稳定后：实盘起步

- 以 **5000–10000元** 实盘起步，**只做1手**。
- 只做模拟阶段验证过的那一种形态。
- 单笔亏损触及总资金2%即无条件离场，不找理由、不调整止损。

### 持续跟踪

- 把USDA月度供需报告、国内油厂豆粕库存周度数据、生猪存栏/养殖利润作为每周必看的三张表。
- 专注豆粕的优势在于变量收敛，但前提是对这些变量的变化保持连续感知，而不是凭盘面感觉交易。

## 九、当前市场矛盾与观察要点（2026年11月背景）

> 以下为示例背景，交易前请核对最新数据。

### 9.1 当前核心矛盾

**外盘偏紧、内盘偏松。**

- **外盘偏紧**：USDA 11月报告下调美豆期末库存至3.00亿蒲，低于预估；美豆对华销售总量1664万吨，远高于去年同期；中国对美豆仍征收13%关税，私营压榨企业缺乏大规模采购美豆的商业动力。
- **内盘偏松**：国内豆粕库存134.69万吨，同比增34.88%，近十年同期高位；现货基差M2701-60至+80元/吨，部分地区走弱；生猪养殖亏损，饲料企业随用随采；11月大豆到港量预计950万吨以上。

### 9.2 观察要点

1. **USDA报告后的预期差是否持续**：库存下调是否被市场充分定价，后续出口数据能否继续支撑。
2. **南美天气**：播种顺利暂无一扰动，但厄尔尼诺背景下“北旱南涝”预期是否升级，决定远月天气升水。
3. **国内油厂库存与基差**：高库存能否去化，基差是否继续走弱，决定内盘压力是否延续。
4. **通关政策**：大豆通关时间延长消息对短期情绪的影响，是否改变供给节奏。
5. **生猪养殖利润**：亏损是否导致产能去化加速，影响远期豆粕需求。
6. **主力合约切换**：M2701向M2705移仓节奏，关注月差变化。

### 9.3 可能的情景

| 情景 | 触发因素 | 豆粕可能表现 |
|---|---|---|
| 外盘利多继续发酵 | USDA继续下调库存、出口强劲、南美干旱 | 成本端抬升，连粕震荡偏强，远月可能更强 |
| 内盘压力主导 | 库存继续累积、基差走弱、需求平淡 | 反弹受限，近月承压，基差走弱 |
| 南美天气升级 | 干旱威胁实质化 | 远月天气升水注入，可能推动预期驱动上涨 |
| 南美丰产兑现 | 播种顺利、降水正常 | 内盘高库存压力重新主导，价格承压 |
| 贸易政策突变 | 关税调整、采购节奏变化 | 成本与供给不确定性放大，波动加剧 |

## 十、常见误区与纪律检查表

### 10.1 常见误区

1. **把“一手便宜”当成“风险低”**：一手保证金低，但杠杆约10倍，反向波动1%就是本金10%。
2. **在震荡市中频繁单边追涨杀跌**：手续费和反复止损会慢性磨损本金。
3. **只看外盘利多，忽视内盘高库存和弱基差**：外盘利多传导为国内上涨需要内盘配合，否则容易冲高回落。
4. **报告日重仓博弈**：USDA报告、极端天气预警时，价格跳空风险大，新手应空仓观望。
5. **亏损后调整止损或扛单**：止损规则写死，触及即离场，不找理由。
6. **主力合约切换前恋战**：临近交割月保证金上调、流动性下降，及时移仓。
7. **模拟盘赚钱就认为实盘也能赚钱**：模拟盘没有真实资金压力，实盘首月以“执行规则”为目标，而非收益。

### 10.2 每日纪律检查表

- [ ] 今天是否按计划交易，而不是凭感觉？
- [ ] 开仓前是否写了逻辑、止损、目标？
- [ ] 单笔亏损是否控制在总资金2%以内？
- [ ] 仓位是否超过总资金20%？
- [ ] 是否在报告日或极端天气预警时仍然重仓？
- [ ] 是否执行了止损，没有扛单？
- [ ] 是否记录了交易日志？
- [ ] 今天的信息是否改变了我对核心矛盾的判断？
