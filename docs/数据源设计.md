# 豆粕数据平台 · 数据源设计（v0.1 草案）

> **文档状态**：本文是 v0.1 设计草案，部分内容是当时的推演，实现后有出入。
> 现行实现以 mp-data/README.md 和 mp-data/app/config.json 为准；
> 本文保留作设计思路的存档，**改动会就地标注「2026-11 更新」**。

> 配套文档：`部署方案.md`（服务器、博客接入、定时任务）
> 状态：待确认。确认后按本文档实现，代码不提前写。
> 核心思路：**围绕一对核心矛盾（外盘成本 vs 内盘供需）建最小数据集，产出"盘前一页纸"，而不是做数据大杂烩。**

---

## 0. 设计原则

1. **只抓能进入判断链的数据。** 筛选器就是手册第三章的映射表，不在表里的指标先不抓。
2. **数字必须自带比较基准。** 单独一个"134.69 万吨"没有意义；有意义的是"同比 +34.9%、5 年同期 89% 分位"。脚本的真正产出是「最新值 + 环比 + 同比 + 历史分位」。
3. **口径锁死并记录来源。** 同一周两个数字可以差 9 万吨（见 §3.1），不记录口径就等于埋雷。
4. **能自动的自动化，不能自动的老实手工。** ~~油厂库存类数据在 Mysteel/卓创手里是付费的，硬爬不可持续。~~
   **⚠️ 该判断已被实践推翻（2026-11）**：Mysteel 豆粕频道 `siliao.mysteel.com/doupo/`
   的文章正文免费可读，油厂库存、开机率、周度到港、华东现货价都能正则提取，
   已由 `mysteel.py` 自动采集。现在只剩**生猪养殖利润**需要手工。
   代价是该站有 HTTP 451 频率防护，日常只能抓同步目标那几篇。
5. **失败不能拖垮站点。** 抓不到就沿用上次值并标黄，而不是页面空白。

## 2. 明确不做的

- 不做全品种（只豆粕 + 必要的豆油、菜粕、美豆）。
- 不做分钟级/tick 行情（日线足够做判断）。
- 不做订单流、龙虎榜预测（龙虎榜 P2 可看，但不进判断链）。
- 不接付费源（第一版），只留接口位。
- 不做自动下单，永远不做。

## 3. 口径与一致性规则（最容易被忽略、也最容易出错的部分）

### 3.1 真实案例：同一天两个相差 9 万吨的库存

2026 年第 46 周，华泰期货研报引 Mysteel 写"豆粕库存 134.69 万吨"，另一家晚评写"125.23 万吨"。两个都标着 Mysteel，但一个是 45 周全样本、一个是 46 周主要油厂。

**规则：**
- 每个指标必须有 `sample`（样本口径）字段，如 `全样本 / 主要油厂 / 50 家饲料企业`。
- 不同 `sample` 视为不同指标，不互相覆盖、不做跨口径比较。
- 发现同指标同日期两个来源冲突 → 两个都存，`quality_flag=conflict`，页面上标出来让人判断。

### 3.2 主力连续合约的坑

`M0` 这类连续合约在换月日会凭空跳空。**规则：**
- 原始数据一律存真实合约（M2701 / M2705 / M2709）。
- 基差、月差、收益率、同比，全部用真实合约算。
- 只有画"长期趋势图"时才允许用连续合约，且图上标注换月点。

### 3.3 基差算法

- 定义：`基差 = 现货价(地区) − 主力合约收盘价`
- 必须同时记录：`地区`、`现货来源`、`基准合约`。
- 手册里写的是 `M2701-60 ~ +80`，即用 M2701 作基准；脚本默认跟随**当前主力合约**，换月后自动切换并在页面提示"基差基准已切换"。
- 现货用收盘价还是午间价：固定一个，写进配置，不随心情变。

### 3.4 时间对齐与时区

- 服务器统一切 `Asia/Shanghai`，数据库存本地日期。
- 美豆收盘在北京时间次日 02:20/03:20（美夏令时差异），所以**盘前一页纸的"美豆"是昨夜收盘**，必须标注日期，不能写成"今日"。
- WASDE 报告在北京时间凌晨 00:00（冬令时 01:00）发布，D1 的更新任务要排在报告日之后的早晨。

### 3.5 单位与精度

统一单位表：价格元/吨、库存万吨、利润元/头、比例 %。数据库只存标准单位，原始单位进 `raw` 快照。浮点保留 2 位，不做四舍五入到整数。

## 4. 存储模型

### 4.1 主表（长表）

```
series_id   指标编号+口径，如 B1.Mysteel.全样本
date        业务日期（YYYY-MM-DD）
value       数值
unit        单位
freq        D / W / M
source_id   来源标识
source_ref  来源链接或文件名
sample      样本口径
ingest_time 入库时间（ISO8601）
quality      ok / stale / manual / missing / conflict
note        备注
```

一行一个指标一天。加指标只加行，不改表结构。

### 4.2 原始快照

每次抓取的原始响应（HTML / JSON / CSV）原样落盘到 `raw/YYYY-MM-DD/<source>-<ts>.<ext>`。
理由：口径以后会变，没有原始快照就无法回溯"当初这个数是怎么来的"。

### 4.3 配置表

- 指标注册表：编号、名称、单位、频率、来源优先级、是否 P0。
- 来源表：名称、类型、URL、超时、重试、失败策略。

## 5. 派生指标公式（写到能直接实现）

| 编号 | 名称 | 公式 |
|---|---|---|
| A5 | 基差 | `现货价 − 主力合约收盘价` |
| A6 | 月差 | `近月结算价 − 远月结算价`（M1-M5、M5-M9、M9-M1） |
| A7 | 豆菜粕价差 | `M 主力 − RM 主力` |
| B5 | 5 年同期分位 | 当前值在「过去 5 年同周历史值」中的百分位 |
| B7 | 同比 | `(本期 − 去年同期) / 去年同期 × 100%` |
| P1 | 盘面压榨利润 | `豆粕价×0.785 + 豆油价×0.185 − 大豆到港成本 − 加工费`（元/吨大豆；出粕率 78.5%、出油率 18.5%、加工费默认 150） |
| P2 | 大豆到港成本 | `(CBOT 美分/蒲 × 0.367437 + 升贴水美分/蒲) × 汇率 × (1+关税) × (1+增值税) + 港杂费` |
| P3 | 内外盘比价 | `美豆折人民币(元/吨) ÷ 豆粕主力(元/吨)` |

> 注：P1/P2 的系数和费用是可以调的配置项，不同机构算法略有差异，页面上要显示"按本系统口径"。

## 6. 展示设计（三层）

### 6.1 第一层：盘前一页纸（核心产物）

每天 08:35 生成，Markdown + HTML 双份。

```markdown
# 豆粕盘前一页纸 · 2026-11-18

## 一句话
外盘成本支撑仍在，但内盘库存高位、基差走弱 → 震荡偏强，不追高。

## 核心矛盾仪表盘
| 维度 | 状态 | 关键数据 | 方向 |
|---|---|---|---|
| 成本端 | 🟢 偏紧 | 美豆 1085美分(↑) USD/CNY 7.12(→) | 支撑 |
| 供给端 | 🔴 偏松 | 豆粕库存 134.69万吨(↓4.25) 同比+34.9% 历史分位 89% | 压制 |
| 需求端 | ⚪ 平淡 | 生猪利润 -120元/头 饲企库存 7.32天(↓) | 中性 |
| 结构 | 🔴 弱 | 基差 -20(↓) 1-5价差 -85(↓) 豆菜粕 780(→) | 压制 |

## 今日必看
- USDA 出口销售：对华 X 万吨（预估 Y）
- 本周库存是否继续去化（分水岭：130 万吨）
- 距 M2701 进入交割月还有 X 个交易日

## 数据体检
⚠️ B1 库存：手工录入（11-16），请核对口径
⚠️ A4 现货：生意社华东报价，与手册基准地区可能不一致
```

设计要点：
- **仪表盘只有四个维度**（成本 / 供给 / 需求 / 结构），对应手册第五章矛盾框架，不堆指标。
- 每个数字后面跟一个箭头（环比方向），括号里是变化量。
- 最后必须有"数据体检"区块，任何 `stale/manual/conflict` 都在这里暴露，**不允许静默降级**。

### 6.2 第二层：周度表

库存、压榨量、基差、月差、豆菜粕价差五条时间序列：
- 最新值 / 环比 / 同比 / 5 年区间带（最低-中位-最高）
- 导出 CSV
- 这张表才是做套利和历史分位的依据

### 6.3 第三层：单文件 HTML 看板（可选，P1）

- 双击可开、离线可用
- 折线图用 ECharts
- 数据直接嵌在文件里，不依赖后端接口

### 判断标准

> 如果这一页纸上没有一句话能直接改变操作，说明数据选错了。

## 7. 获取分层与失败降级

| 层 | 方式 | 代表源 | 稳定性 | 定位 |
|---|---|---|---|---|
| L0 | 手工录入 | 油厂库存、开机率、养殖利润 | 永不断供 | **第一版就做，兜底** |
| L1 | 官方接口 | 大商所、统计局、海关、USDA QuickStats / FAS / PSD | 高 | 主力 |
| L2 | 免费库 | AkShare（期货、库存、现货基差） | 中（上游会变） | 换速度，加告警 |
| L3 | 网页抓取 | 生意社现货价、期货公司周报 | 低（反爬） | 只抓非核心 |
| L4 | 付费 API | Mysteel、卓创、Wind、iFinD | 高 | 留接口位，暂不接 |

**降级规则：**

| 情况 | 处理 |
|---|---|
| 单个来源失败 | 重试 2 次（间隔 3s），仍失败 → 用上次值 + `stale` |
| 连续 3 天失败 | 页面顶部红条告警 + 日志 WARN |
| 两源冲突 | 都存，标 `conflict`，页面提示 |
| 手工数据超 10 天未更新 | 标 `stale`，仪表盘该项置灰 |
| 整次任务失败 | 保留上一次生成的页面，不覆盖成空白 |
