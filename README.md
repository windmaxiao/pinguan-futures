# 品观 · 期货品种数据与研究台

> 一个品种，一套框架，一页纸。

把「公开行情 + 产业数据 + 新闻资讯」变成一张**盘前一页纸**和一份**每日简报**的小系统。

**零第三方依赖**——纯 Python 标准库，`python3` 就能跑，不需要 pip install。

- 站点示例：`https://data.<你的域名>/`
- 设计文档：[数据源设计](docs/数据源设计.md) · [部署方案](docs/部署方案.md) · [运维交接](docs/交接说明.md)
- 交易研究笔记：[豆粕期货专注交易研究手册](docs/豆粕期货专注交易研究手册.md)

## 访问门禁

站点默认要求输入**访问码**才能查看，解锁后 **7 天免输**。

| 权限 | 凭据 | 有效期 | 能做什么 |
|---|---|---|---|
| 只读 | 访问码 | 7 天 | 看板、简报、周度数据 |
| 读写 | 管理码 | 1 天 | 录入数据、生成访问码、开关门禁 |

- 访问码与管理码都只存 **SHA-256 哈希**，文件里查不到明文
- 解锁凭证是 HMAC 签名的 cookie（`auth` 与 `admin` 两种 scope，不能互相冒充）
- 录入页与 `/api/manual` 都要求管理码，**分享访问码出去别人只能看不能改**

```bash
# 服务器上
python3 app/auth.py status          # 查看状态与访问码指纹
python3 app/auth.py gen             # 生成新访问码并开启门禁
python3 app/auth.py on|off          # 开关门禁
python3 app/auth.py secret          # 轮换签名密钥（所有会话失效）
```

## 主要能力

| 模块 | 内容 |
|---|---|
| **行情** | 新浪财经：豆粕/豆油/菜粕/生猪期货，合约按交割月自动滚动 |
| **成本端** | CBOT 美豆、美元人民币汇率、进口大豆含税到港成本 |
| **供给端** | 油厂豆粕/大豆库存、开机率、盘面压榨利润 |
| **需求端** | 生猪自繁自养利润、生猪期货主力 |
| **结构** | 基差、月差、豆菜粕价差 |
| **资讯** | 金十数据：快讯 / 深度资讯 / 财经日历，按关键词过滤 |
| **四维判断** | 成本 / 供给 / 需求 / 结构，规则驱动，结论可追溯 |
| **简报** | 每天 07:30 生成豆粕简报 + 全局简报，AI 写导语，邮件推送 |
| **复盘** | 记录每日判断与模拟盘，自动算判断准确率、胜率、盈亏归因 |
| **告警** | 任务崩溃、数据超期、异常值，邮件通知（可选 Server酱） |
| **自愈** | 每次运行用日线接口核对近 6 天结算价，缺失自动补齐 |

## 架构

```
定时任务
  ├─ 08:35 / 15:10 / 17:30   抓行情 → 算派生 → 渲染页面 → 数据体检
  ├─ 08:00–22:30 每 30 分钟   只抓快讯，命中关键词即推送
  ├─ 07:30                   抓隔夜资讯 → 生成双简报 → 发邮件
  ├─ 18:30                   Mysteel 采集 → 同步产业数据 → 重渲染
  ├─ 08:10                   USDA WASDE 检查（有新报告才写库）
  └─ 03:20                   备份数据库

写入
  网页录入 → nginx(访问码门禁) → 127.0.0.1:8765 → SQLite → 重新渲染

输出
  纯静态 HTML（无前端框架），nginx 直接托管
```

## 快速开始（本地试跑）

```bash
cd mp-data

# 1. 回填历史日线（可选，但建议）
python3 app/fetch.py --backfill-all

# 2. 录入手工数据（示例值）
python3 app/manual.py set A4.spot 3074
python3 app/manual.py weekly --inv 125.23 --soy 795.39 --rate 48.88

# 3. 抓行情、算派生、生成页面
python3 app/fetch.py
python3 app/render.py

# 4. 本地预览
python3 -m http.server 8000 --directory site
# 打开 http://127.0.0.1:8000/
```

`site/index.html` 双击也能直接看（纯静态、无外部依赖）。

## 部署到服务器

```bash
# 上传后在服务器执行
sudo bash mp-data/install.sh
```

> ⚠️ 仓库里的 `data.example.com` 是**占位符**，部署前要换成你自己的域名，
> 涉及 5 个应用文件和 1 个 systemd 单元，具体清单见
> [mp-data/README.md](mp-data/README.md#部署到服务器)。

会自动创建 `mpdata` 用户、装好 systemd 定时任务、建立 `/srv/mp-data` 目录结构。
之后需要手动配置三样东西（都在 `/etc/mp-data/`，权限 600）：

| 文件 | 用途 | 是否必需 |
|---|---|---|
| `notify.json` | 邮件 / Server酱 告警 | 建议 |
| `jin10.json` | 金十 MCP Token（资讯） | 可选 |
| `llm.json` | OpenAI 兼容接口（简报 AI 导语） | 可选 |

详见 [mp-data/README.md](mp-data/README.md)。

| 手工录入 | 生猪养殖利润 |

## 已知约束

- 大商所官网有 WAF（HTTP 412），行情统一走新浪，不用官方接口
- 产业数据以 Mysteel 免费频道为主，HTML 结构变更即失效；实测一天抓约 250 篇会触发 HTTP 451
- 生猪养殖利润无免费源，只能手工录入
- 金十外盘行情不含农产品，补不了「美豆历史」
- 新浪 7x24 快讯实测信息密度过低（500 条 1 条），默认关闭
- 分位按全部历史样本计算（非 5 年同期）；样本不足 8 条时页面不显示分位条
